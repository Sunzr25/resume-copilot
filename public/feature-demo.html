📚 功能2：面经库自动同步

工作流程

  1. 用户点击职位卡片
  2. 触发 handleSelectJob() 函数
  3. 更新 UI 选中状态
  4. 过滤本地面经库查找该公司/职位相关问题
  5. 如无相关面经，调用 API 获取
  6. 自动合并到面经库（自动去重）
✅ 智能合并机制
系统会自动去重，确保不会出现重复的面经内容

API 交互

// 获取职位相关面经 GET /api/recruitment/jobs/{jobId}/interviews // 响应格式 { "success": true, "interviews": [ { "question": "介绍一下React的生命周期", "answer": "React的生命周期分为...", "difficulty": "medium", "frequency": 3 } ] }

🚀 推荐改进：自动推荐职位

💡 如何工作
用户打开 Recruitment 页面时，系统会自动基于用户的 Profile（技能、经验等）调用 Kimi API 生成个性化的职位推荐，无需用户手动搜索或输入条件。

自动加载流程

  1. 页面加载→自动获取用户 Profile
  2. 调用 /api/recruitment/recommended-jobs API
  3. Kimi API 基于用户技能生成 5 个推荐职位
  4. 智能合并到职位列表（避免重复）
  5. 每 5 分钟自动更新一次职位推荐

推荐职位内容示例

{ "company": "字节跳动", "position": "前端工程师", "salary": "30-50k", "location": "深圳", "description": "负责字节系产品的前端开发...", "source": "boss" }
